# 族谱树扇形视图（Fan View）技术评审报告

> P1 增强 · 蓝图 §7.1 族谱树布局与渲染  
> 评审人：前端架构 | 日期：2026-09-07 | 状态：**评审通过待排期**  
> 关联代码：`utils/family-tree-layout.js`（树形/直系共用布局）、`components/common/TreeGraph.vue`（Canvas 渲染）

---

## 一、需求背景

蓝图 §7.1 将「扇形/方块视图」列为 P1 增强（MVP 仅树形 + 直系）。扇形视图以**焦点人物为圆心**、**世代为同心圆环**、**家庭单元为扇区**向外展开，是族谱领域经典可视形态（参考 Family Echo / Gramps Fan Chart），在中老年用户与「一族全貌」场景中认知度最高。

**目标**：与树形视图共用同一份节点数据，仅替换布局函数；渲染沿用现有 Canvas 双缓冲管线，控制性能与包体增量。

---

## 二、现状勘察（可复用资产）

| 资产 | 位置 | 复用度 | 说明 |
|-----|------|:------:|------|
| 节点数据 | `member.tree` 物化路径节点集 | ★★★★★ | 五世窗口 ~100–500 节点，含 path/generation/spouseId/birthOrder |
| 树形布局 | `utils/family-tree-layout.js computeLayout` | ★★★★ | tidy 递归、家庭单元宽度、兄弟排序逻辑可直接抽取 |
| 直系过滤 | `filterDirectLine` | ★★★ | 扇形「直系展开」可复用 path 前缀逻辑 |
| 时间轴过滤 | `timelineFilter` | ★★★ | 扇区按在世年份收缩可复用 |
| 五服色板 | `wufuColor` + WU_FU_COLORS | ★★★★★ | 扇形五服着色（同心环语义天然契合五服） |
| Canvas 渲染 | `components/common/TreeGraph.vue` | ★★★ | 视口裁剪 / 离屏缓冲 / 手势 transform 管线可平移 |
| 性能优化 | `utils/tree-perf.js` | ★★★★ | 视口剔除 + 降级策略沿用 |

**结论**：扇形视图**不需要**重写数据层与渲染管线，核心工作 = 新增一个「极坐标布局纯函数」+ TreeGraph 增加视图模式开关。

## 三、布局算法方案

### 3.1 坐标模型

```
焦点人物 → 圆心 (cx, cy)
世代 g → 半径环 R(g) = R0 + (g − gFocus) × RING_STEP
家庭单元 → 角度扇区 θ，按 顺时针 自 12 点方向 展开
```

| 参数 | 初值 | 说明 |
|-----|:----:|------|
| R0（中心卡半径） | 70px | 焦点人物自身 |
| RING_STEP（环间距） | 96px | 需容纳 120×50 卡或缩小为胶囊 |
| 节点卡形态 | 胶囊（无头像）或 姓名+世序 | 扇区径向空间有限，禁头像大卡 |

### 3.2 布局步骤（纯函数 fanLayout(nodes, focusPath)）

```
输入：五世窗口节点集（同 computeLayout）+ focusPath
1. 家族化：抽家庭单元 [夫,妻]（复用 familyWidth/spouseIdOf 判定）
2. 按代分环：世代差 Δ = generationOf(path) − generationOf(focusPath)
   · Δ=0 中心（本人 + 配偶，若在集）
   · Δ>0 后代外环；Δ<0 祖先内环（环半径向中心收缩，Δ 为负时 R 取 R0+|Δ| 反向）
3. 环内角序：同一家庭单元连续占用 θ 区间，区间宽 ∝ 该家庭子代数（含其下展开）
   · 区间宽 angularWidth(family) = min(90°, max(20°, 12°×(展开子代数+1)))
   · 兄弟按 birthOrder 顺时针排列（复用 sortChildren）
4. 极坐标 → 笛卡尔：x = cx + R·cos(θ), y = cy − R·sin(θ)
5. 连线：父单元扇区中线 → 子单元扇区起点，沿圆弧贝塞尔（三次曲线，控制点取中间半径）
6. 输出 nodes(x,y,radius,angleRange) + edges + 同心环元数据
```

### 3.3 与树形布局的关系

| 维度 | 树形 computeLayout | 扇形 fanLayout |
|-----|-------------------|---------------|
| 坐标系 | 笛卡尔 (x=兄弟横铺, y=世代下行) | 极坐标 (r=世代环, θ=家庭扇) |
| 输入 | nodes + 隐含 focus 窗口 | nodes + focusPath（必需） |
| 输出 | nodes{x,y}/edges/width/height | nodes{x,y,r,θ}/edges/rings |
| 通用件 | familyWidth / spouseIdOf / sortChildren / generationOf | **同左（直接 import）** |
| 调用方 | TreeGraph 树形模式 | TreeGraph 扇形模式（switch layout fn） |

> 架构关键：**视图 = 数据 + 布局函数 + 渲染**。数据一次拉取，`computeLayout`/`fanLayout` 任一布局产出坐标，Canvas 只画坐标。切换视图 = 换函数 + 动画补间（见 §6）。

## 四、渲染与性能方案

| 项 | 方案 | 依据 |
|----|------|------|
| 画布 | 沿用现有 Canvas 2D（组件已有离屏缓冲） | 不引入 G6（§2.1 定案，包体/兼容） |
| 视口裁剪 | 仅绘制 θ 区间在当前视口内的扇区 | tree-perf 现成视口剔除改造为环形判定 |
| 降级 | 节点 >300 → 只画名字圆点（复用树形降级逻辑） | §7.1「节点>300 降级方块视图」 |
| 缩放 | 双击/手势缩放；放大至家族级别时局部切回树形展开 | 扇区文字随 R 缩放，<40% 只显圆点 |
| 性能目标 | 500 节点首帧 <800ms，环形拖拽/旋转 60fps | 对齐 §7.1 |

**渲染细节**：文字沿径向排布（非水平）——旋转 ctx 使姓名垂直于弧线，保证中老年可读；配偶双名同扇区上下两行。

## 五、交互设计

| 交互 | 行为 |
|-----|------|
| 中心点击 | 焦点切换：点击某扇区人物 → 该人成为新圆心 → 重拉数据 + 动画补间（同心缩放过渡） |
| 扇区点击 | 弹层简卡（复用现有简卡三按钮：请安/详情/关系） |
| 旋转 | 单指拖拽绕圆心旋转（角度偏移量应用到所有 θ） |
| 缩放 | 双指捏合；双击放大一级 / 双击缩小复原 |
| 五服模式 | 同心环按世代自动对应五服色（本人=中心朱砂 → 向外 斩衰→同宗），高亮选中五服区间 |
| 视图切换 | 树形 ⇄ 扇形 顶部切换，淡入淡出 ≤200ms（不重拉数据） |
| 时间轴 | 滑块过滤后重新布局（复用 timelineFilter） |

## 六、风险与对策

| # | 风险 | 等级 | 对策 |
|--|------|:----:|------|
| 1 | 深代（>6 代）环密集文字重叠 | 高 | 窗口默认 5 世；扇形仅展开焦点直系 + 平辈，其余环显示「n 人」聚合扇区，点击下钻 |
| 2 | 扇形文字旋转可读性 | 中 | 径向排布 + 字号自适应 R；视口内文字重排（局部重绘离屏层） |
| 3 | 动画补间性能 | 中 | 仅对节点位置做 transform 补间（不改布局），>200 节点关闭动画直接跳转 |
| 4 | 与既有树形回归 | 低 | 新增纯函数 fanLayout 独立单测；TreeGraph 视图模式枚举化，树形路径零改动 |
| 5 | 色弱/对比度 | 低 | 五服配色沿用现有色板并叠加角标文字，不单靠颜色 |

## 九、结论与建议

1. **技术可行**：复用纯函数布局族 + 既有 Canvas 管线，增量集中在 1 个布局函数与组件模式开关，无架构风险；
2. **建议拆期**：一期静态扇形（2 周）→ 二期交互动画与聚合下钻（2 周）；
3. **前置条件**：功能开关 `treeFanView`（settings 已有键位，17.2 已预留），默认关闭灰度；
4. **排期建议**：并入 V2.0 上线后第一个 P1 迭代包（与家乐园子系统并行，两者无资源冲突）。
