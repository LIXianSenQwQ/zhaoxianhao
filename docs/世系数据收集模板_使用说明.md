# 世系数据收集 Excel 模板（试点 200 人）· 使用说明

> 主文件：`docs/世系数据收集模板_试点200人.xlsx`（真实 Excel，含下拉验证）
> 生成器：`scripts/gen-excel-template.ps1`（可改列后重跑）
> 配套：`docs/世系数据收集说明.md`（族务对接完整纪律）

## 文件结构（3 个工作表）

| 工作表 | 内容 |
|---|---|
| **世系数据** | 20 列采集主表；必填列表头朱砂字（本名/性别/世代数/房支/在世状态/信息来源/录入人）；第 2 行为示例 |
| **字段清单与校验规则** | 20 个字段 × 5 列：模板列 / 对应 members 字段 / 必填 / 填写格式示例 / 服务端校验规则 |
| **参考数据** | 下拉选项源（性别/在世状态/信息来源/房支）+ 8 条填表提示；**房支列在此增删后下拉自动生效** |

## 内置下拉数据验证（打开即用）

- **性别**：男 / 女（C 列）
- **房支**：长房～七房（H 列，在参考数据 D 列增删）
- **在世状态**：在世 / 已故（M 列）
- **信息来源**：口述/老谱/碑刻/文书/推测（R 列）

> 下拉范围预留到第 501 行（500 条数据）；选中单元格会显示输入提示。

## 重新生成（改字段后）

```powershell
pwsh -NoProfile -File scripts/gen-excel-template.ps1
```

- 无第三方依赖：脚本用 .NET 手工构造最小 OOXML 包（[Content_Types].xml / workbook / 3 个 sheet / styles），每个 part 落盘前做 XML well-formed 校验。
- 输出覆盖写 `docs/世系数据收集模板_试点200人.xlsx`。

## 校验规则摘要（详见工作表 2，与 members 集合对齐）

1. **日期**：`YYYY-MM-DD` 或「约」前缀；逝世 ≥ 出生；与在世状态互斥
2. **世代数**：正整数且父子连续（父世代 = 子世代 - 1）——服务端互指校验
3. **父母姓名**：须与某人「本名」逐字一致才能自动挂接关系边
4. **排行**：同父母下唯一
5. **隐私**：身份证/病历/财务/墓葬坐标一律不收集
6. **来源**：每条标口述/老谱/碑刻/文书，存疑必标「推测」
