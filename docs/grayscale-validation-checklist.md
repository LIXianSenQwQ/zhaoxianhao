## 二、性能埋点采集（utils/request.ts 已内置）

```typescript
// 首页加载完成后，控制台执行（或接灰度数据上报）：
import { getPerfReport } from '@/services/request';
const report = getPerfReport();
// → { total, slowCount, avgMs, budget: 200 }
```

| 采集项 | 来源 | 阈值 |
|-------|------|:----:|
| API 平均延迟 | getPerfReport().avgMs | ≤200ms |
| 慢调用数 | getPerfReport().slowCount | 每会话 <3 |
| 缓存命中率 | call().fromCache | ≥60% |
