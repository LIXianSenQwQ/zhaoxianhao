# V3.0 DNA 真实对接 — 族人访谈需求收集表

**项目阶段**: V3.0 P1 (23andMe / AncestryDNA / WeGene 对接)  
**访谈周期**: 2026-10 至 2026-11（共 8 周）  
**目标样本**: ≥ 20 位族人（覆盖各支系/年龄段/教育背景）

## 🎯 核心访谈问题清单

### Part A: 现状与痛点（10 min）

1. 您目前了解自己的家族历史来源是什么方式？（口述/族谱/地方志/DNA）
2. 您是否做过 DNA 检测？如果是，结果对您理解家族历史有何帮助/局限？
3. 在使用现有家谱系统时，最让您困惑或不满的功能是什么？
4. 您期望 DNA 数据在家谱系统中如何呈现？（单倍群标签/地图可视化/族人匹配列表）

### Part B: DNA 数据接受度（15 min）

5. 您愿意让族史委看到您的 DNA 检测结果吗？
   - [ ] 完全愿意
   - [ ] 仅愿意看到单倍群（Y/MT），不愿暴露 SNPs
   - [ ] 完全不愿意
6. 您如何看待"基于 DNA 的族人匹配"功能？
   - 可以接受系统推荐"可能的亲戚"
   - 希望仅在我主动搜索时才显示匹配结果
   - 不希望被任何人通过 DNA 找到
7. 如果检测结果与族谱记载冲突（如某支系 Y 单倍群不同），您希望系统如何处理？
   - 自动标记异常，由族史委人工复核
   - 显示"存疑"标签，不影响正常显示
   - 隐藏冲突，避免争议
8. 您对 DNA 数据隐私的最大担忧是什么？

### Part C: 功能优先级排序（10 min）

请对以下 V3.0 候选功能按重要性排序（1=最重要，5=最不重要）：

| 功能 | 说明 | 排序 |
|------|------|------|
| 单倍群展示 | 显示 Y/MT 单倍群标签与迁徙路线图 | ___ |
| 族人匹配 | 基于 cM 值推荐可能的血缘亲属 | ___ |
| 族群比例 | 显示各地域血统百分比（如北方汉 85%） | ___ |
| 古 DNA 对比 | 与考古遗址古人 DNA 比对（如仰韶文化） | ___ |
| 健康风险提示 | 基于遗传标记提示健康风险（需合规审查） | ___ |

### Part D: 付费意愿（5 min）

9. 如果 DNA 对接功能需要付费使用，您可接受的价格区间是？
   - [ ] 免费基础功能 + 付费高级匹配（如 99 元/年）
   - [ ] 一次性付费 199-399 元
   - [ ] 希望完全免费（由宗族基金赞助）
   - [ ] 不愿意为此付费
10. 您是否愿意支付额外费用以获得更精确的检测（如全基因组 vs 常规 STR）？

### Part E: 用户体验偏好（5 min）

11. 您希望通过什么方式录入 DNA 数据？
    - [ ] 授权第三方平台自动同步（23andMe OAuth）
    - [ ] 上传原始数据文件（CSV/zip）
    - [ ] 手动填写关键指标（单倍群/采样机构）
12. 您期望 DNA 结果在家谱页面如何展示？
    - [ ] 独立标签页"基因档案"
    - [ ] 在成员详情卡片中显示简化图标
    - [ ] 在家族树中以特殊颜色/图标标识
    - [ ] 仅管理员可见，不公开展示

### 数据汇总方式

1. **定量分析**: 使用 Google Sheets 或飞书多维表格统计功能排序/付费意愿
2. **定性分析**: 使用卡诺模型（Kano Model）分类功能为：
   - 必备属性 (Must-have): 数据隐私保护
   - 期望属性 (Performance): 单倍群展示
   - 兴奋属性 (Delight): 古 DNA 对比
3. **输出物**: `docs/V3.0-DNA-User-Research-Summary.md` + 向族史委汇报 PPT

## ⚖️ 伦理与合规要点

### 访谈过程
- 所有受访者签署知情同意书（明确数据用途、匿名化处理、可随时退出）
- 不诱导、不承诺、不夸大功能
- 对敏感回答（如非婚生子女/抱养疑虑）严格保密

### 产品设计启发
- **隐私优先**: 默认隐藏敏感数据，用户主动 opt-in
- **家族和谐**: 冲突数据不自动公开，需族史委调解
- **文化尊重**: 避免让 DNA 结果动摇传统宗族认同
- **合规审查**: 涉及健康信息需医疗机构参与审核
