## 一、核心理念与设计标准

### 1.1 设计理念

本框架以**国际家谱证据标准（Genealogical Proof Standard, GPS）** 为学术根基，以**中国传统文化**为精神内核，打造「总谱统宗、分谱明系、支谱详世」的三级家谱管理体系。

| 理念 | 内涵 | 落地要求 |
| --- | --- | --- |
| **学术严谨** | 每条记录有据可查，每段关系可验证 | 来源标注率100%，证据分级管理 |
| **文化传承** | 保留姓氏源流、堂号郡望、字辈派语、家规家训 | 文化元素结构化存储 |
| **多分支协同** | 总谱统一、分谱自治、支谱灵活 | 三级权限体系，分支独立编辑 |
| **数据主权** | 用户拥有数据完全控制权 | 支持GEDCOM导入导出、JSON备份、本地存储 |
| **久远传承** | 百年尺度数据可读 | 开放格式归档、多重备份、跨代传承 |

### 1.2 对标行业最高标准

| 对标维度 | 行业标准 | 本框架实现 |
| --- | --- | --- |
| **数据格式** | GEDCOM 5.5.1/7.0国际标准 | 完整支持导入导出 |
| **证据标准** | 家谱证据标准（GPS） | 来源标注、证据分级、置信度标记 |
| **多分支管理** | 支持总谱/分谱/支谱三级 | 分支独立数据库+统一索引 |
| **可视化** | 树形图、扇形图、直系图、时间轴、地理迁徙图 | 5种以上视图模式 |
| **协作能力** | 多人在线协同编辑 | 分支级权限+审核流 |
| **AI能力** | OCR识别、智能排版、古谱识别 | OCR入谱、智能挂接、AI辅助编修 |
| **数据安全** | 加密存储、多重备份、权限控制 | L1-L5分级+端到端加密 |

### 2.2 谱系层级定义

| 层级 | 名称 | 定义 | 范围 | 管理权限 |
| --- | --- | --- | --- | --- |
| **总谱** | 通谱/大宗谱 | 郝氏全族统一谱系，含所有分支 | 全国/全球郝氏 | 族长+族史委 |
| **分谱** | 房谱/派谱 | 同一始祖下各大房分支 | 一房之内 | 房长+族史委 |
| **支谱** | 支谱/家谱 | 同一房下各地迁徙分支 | 一地一支 | 支长+房长 |

## 五、分支间逻辑互补与数据一致性

### 5.1 分支间数据一致性规则

| 规则 | 说明 | 校验方式 |
| --- | --- | --- |
| **始祖一致** | 所有分支始祖指向同一人（总谱始祖） | 数据库外键约束 |
| **世代对齐** | 各分支世代数从始祖统一计算 | 自动校验+人工复核 |
| **字辈对齐** | 同世代字辈字全族统一 | 总谱字辈表约束 |
| **编码唯一** | 分支编码全局唯一 | 数据库唯一索引 |
| **人物唯一** | 同一人不可同时在两个分支（迁徙除外） | 身份证/唯一标识去重 |
| **关系闭环** | 父子关系形成闭环，无悬空节点 | 图数据库校验 |

### 5.2 分支间逻辑互补

| 互补关系 | 设计 |
| --- | --- |
| **总谱→分谱** | 总谱提供全族索引，分谱提供详细世系 |
| **分谱→支谱** | 分谱提供房内总览，支谱提供一地详录 |
| **迁徙→分支** | 迁徙记录连接源分支与目标分支 |
| **谱名→字辈** | 谱名字辈字与总谱字辈表实时校验 |
| **称谓→关系** | 称谓计算基于全局关系图 |

### 5.3 合并冲突处理

当两个分支确认为同一支系需要合并时：

1. 识别重复人物（姓名+世代+父名+母名四维匹配）
2. 标记冲突节点
3. 人工审核确认
4. 合并数据（保留双方来源标注）
5. 更新分支编码
6. 生成合并报告
