## Schema 变更清单

本次补齐新增字段（均为可选，不影响现有写入）：

### members.schema.json
```json
"generationChar": ["string", "null"],         // 字辈字（框架§3.1）
"aliases": { "type": "array", maxItems: 10 }, // 字号/曾用名（框架§3.1）
"birthPlace/deathPlace": "string",           // 出生/逝世地（框架§3.1）
"siblingOrder": "integer 1-99",              // 同父排行（框架§3.1）
"occupation/education": "string",            // 职业/功名（框架§3.1）
"tomb": { "location", "fileId", "note" },    // 墓葬（框架§3.1）
"sourceTags": ["string"]                     // 来源标注（框架§3.2，必填语义）
"confidence": "integer 1-5",                 // 置信度（框架§3.3）
"version": "integer"                         // 记录版本号（框架§3.1）
```

**注意**: status enum 从 `[ALIVE, DECEASED]` → `[ALIVE, DECEASED, UNKNOWN]`
