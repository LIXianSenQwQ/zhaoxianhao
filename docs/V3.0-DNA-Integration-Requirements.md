## 一、项目背景与目标

### 1.1 现状

- **当前占位**: `dna_records.schema.json` 已定义 Y-DNA/MT-DNA/AUTOSOMAL 三种测试类型基础字段，但无真实数据源接入
- **业务缺口**: 族史委无法通过客观遗传证据辅助血缘关系验证，仅依赖口述史/文献记载
- **技术约束**: 所有商业化 DNA 检测报告格式不一，需标准化解析 + API 对接双路径覆盖

### 1.2 核心目标

✅ **Phase 1 (V3.0 P1)**: 实现 23andMe/AncestryDNA 官方 API 对接（REST OAuth2）  
✅ **Phase 2 (V3.0 P2)**: 支持微基因 (WeGene) 国内检测服务接入  
✅ **Phase 3 (V3.0 P3)**: 离线上传 raw data CSV → 本地解析引擎（隐私敏感场景）  

### 1.3 成功标准

| KPI | Target |
|-----|--------|
| 支持检测平台数 | ≥ 3 (23andMe, AncestryDNA, WeGene) |
| 解析准确率 | > 95% (对标准 SNP panel) |
| 血缘判定一致性与传统方法对比 | ≥ 90% |
| 用户授权耗时 | < 5 min (OAuth2 redirect flow) |
| 隐私合规 | GDPR/PIPA double compliant (sensitive L1 data) |

### 2.2 Schema Security Principles

- **Field-Level Privacy**: `snps`/`relativeMatches` 默认隐藏（需 explicit consent）
- **Audit Trail**: All reads/writes logged to `audit_logs::dna_access`
- **Role-Based Masking**: MEMBER users cannot see other users' haplogroups without cross-user matching opt-in
- **Export Restriction**: Only HISTORIAN+ can export raw SNP arrays; all exports must include watermark

#### 3.2.1 OAuth2 Flow

```javascript
// Services/DNAProviders/twentyThreeAndMe.ts
class TwentyThreeAndMe implements DNAProvider {
  name = '23andMe';
  
  async authenticate() {
    const authUrl = 'https://api.23andme.com/oauth/authorize?';
    const params = new URLSearchParams({
      client_id: process.env.DNA_23ANDME_CLIENT_ID,
      response_type: 'code',
      scope: 'profiles,race_by_biomarker,y_haplotype,mhaplotype,locations_snps,genome_data_privacy_agreement',
      redirect_uri: `${BASE_URL}/api/v3/dna/callback`
    });
    
    // Redirect user to 23andMe login page → get authorization code
    return { url: authUrl + params.toString() };
  }
  
  async handleCallback(code: string): Promise<AuthTokens> {
    const res = await axios.post(
      'https://api.23andme.com/oauth/token',
      new URLSearchParams({ code, grant_type: 'authorization_code' }),
      { headers: { Authorization: 'Basic ' + Buffer.from(`${CLIENT_ID}:${SECRET}`).toString('base64') } }
    );
    return { accessToken: res.data.access_token, ... };
  }
  
  async fetchYHaplogroup() {
    const res = await axios.get('https://api.23andme.com/3/profiles/me/y_haplotype/', {
      headers: { Authorization: `Bearer ${this.accessToken}` }
    });
    return { yHaplogroup: res.data.haplogroup };
  }
}
```

### 3.5 Unified Orchestrator Pattern

```typescript
// services/dna/orchestrator.ts
class DNAManagementService {
  
  async syncFromProvider(memberId: string, providerName: string): Promise<DNAResult> {
    const provider = this.createProvider(providerName);
    
    try {
      // Step 1: Ensure user has re-consented within last 90 days
      const consentValidated = await this.validateConsent(memberId, providerName);
      
      // Step 2: Pull data (Y/MT/Autosomal as available)
      const profile = await provider.fetchProfile();
      const haplo = await provider.fetchHaplogroups();
      const ethnicity = await provider.fetchEthnicityEstimates();
      const snps = consentValidated.autosomal ? await provider.fetchSNPs() : null;
      
      // Step 3: Deduplicate against existing record (upsert)
      const merged = await this.upsertRecord(memberId, {
        ...profile, ...haplo, ethnicity, snps,
        lastSyncAt: new Date(),
        dataSource: 'api_pull'
      });
      
      // Step 4: Trigger downstream analysis (haplogroup clustering, relative search)
      await this.scheduleRelativeMatching(merged._id);
      
      return { success: true, recordId: merged._id };
    } catch (error) {
      if (error.code === 'RATE_LIMIT_EXCEEDED') {
        return { 
          success: false, 
          error: 'Too many requests; retry in 1 hour',
          retryAfter: error.retryAfterSeconds 
        };
      }
      throw error;
    }
  }
}
```

## 四、血缘关系推演引擎

### 4.1 遗传距离计算

#### 4.1.1 Y-STR Distance Matrix

```javascript
// utils/dna/y-str-distance.ts
function calculateYStrDistance(strA: YSTRMarker[], strB: YSTRMarker[]): number {
  // Calculate number of steps between STR repeats across 37-marker or 111-marker panels
  let distance = 0;
  const byDys = new Map();
  strA.forEach(m => byDys.set(m.dysNumber, m.repeatCount));
  strB.forEach(m => {
    const a = byDys.get(m.dysNumber);
    if (a !== undefined) distance += Math.abs(a - m.repeatCount);
  });
  return distance;
}

const THRESHOLD_37_MARKER = 5;  // 37-marker ≤ 5 steps → likely same paternal line within 8 gens
const THRESHOLD_111_MARKER = 10; // 111-marker ≤ 10 steps → strong evidence for recent common ancestor
```

#### 4.1.2 Autosomal cM Matching

```javascript
// utils/dna/autosomal-matching.ts
function predictRelationship(sharedCm: number, chromosomeCount?: number): string {
  // Based on ISOGG/Shared cM Project 2020 data
  if (sharedCm >= 3400) return 'Parent/Child';
  if (sharedCm >= 2300) return 'Siblings';
  if (sharedCm >= 1300) return 'Half Sibling / Grandparent / Uncle-Aunt';
  if (sharedCm >= 700) return 'First Cousin';
  if (sharedCm >= 350) return 'Second Cousin';
  if (sharedCm >= 200) return 'Third Cousin';
  return 'More distant than third cousin';
}

function estimateTMRCA(cM: number, generationSpan = 25): number {
  // TMRCA (Time to Most Recent Common Ancestor) estimation using Kimura 2-parameter model
  // Simplified formula: generations ≈ log2(cM / 0.5) * generationSpan
  const generations = Math.round(Math.log2(cM / 0.5) * (generationSpan / 25));
  return Math.max(0, generations);
}
```

### 4.2 家族树融合算法

```typescript
// utils/dna/tree-fusion.ts
interface FusionResult {
  candidateMembers: MemberWithDNA[];
  confidenceScore: number; // 0–1 range
  reasoning: string[];
}

async function mergeDNAWithGenealogy(personId: string, targetMemberId: string): Promise<FusionResult> {
  const personRecord = await getDNARecord(personId);
  const targetRecord = await getDNARecord(targetMemberId);
  
  if (!personRecord || !targetRecord) {
    throw new Error('One or both participants lack DNA data');
  }
  
  // Step 1: Haplogroup compatibility check
  const yCompatible = personRecord.yHaplogroup && targetRecord.yHaplogroup && 
                    isHaplogroupSubclade(personRecord.yHaplogroup, targetRecord.yHaplogroup);
  
  // Step 2: Autosomal match score
  const cmShared = computeSharedCm(personRecord.snps, targetRecord.snps);
  const relationship = predictRelationship(cmShared);
  
  // Step 3: Genealogical path verification
  const expectedCM = calculateExpectedCM(relationship, generationDiff);
  const confidenceScore = clamp(1 - Math.abs(cmShared - expectedCM) / expectedCM, 0, 1);
  
  return {
    candidateMembers: [targetMemberId],
    confidenceScore,
    reasoning: [
      yCompatible ? '✔ Y-haplogroup subclade match' : '✘ Y-haplogroup mismatch',
      `✔ Autosomal match: ${cmShared.toFixed(1)} cM → predicts ${relationship}`,
      `Confidence: ${(confidenceScore * 100).toFixed(0)}%`
    ]
  };
}
```

### 5.2 Regulatory Requirements

| Jurisdiction | Law | Key Requirement | Implementation |
|--------------|-----|-----------------|----------------|
| EU | GDPR Art. 9 | Special category data processing | Explicit consent, right to erasure, data portability |
| US | CCPA | Consumer privacy rights | Opt-out of sale, access logs |

- **Encryption**: At-rest AES-256; in-transit TLS 1.3
- **Key Management**: Cloud KMS with separate keys per testType (Y/MT/Autosomal)
- **Access Control**: MEMBERS can only read their own data; HISTORIAN+ requires audit trail approval
- **Anonymization Pipeline**: Research datasets stripped of identifiers before aggregation
