# 05 八大核心要素研究框架与待证清单

> 本文件为**研究作业指导书**。每一要素包含：①已掌握通史/区域基础（可引用）；②本支专属的待证问题清单（【待田野考证】）；③调查与写作模板（填入实证后成为成果）。严禁跳过实证环节直接撰写结论。

---

## 总则：证据链格式（每条结论必须满足以下结构）

```
[标题] 某项家族事实 → [来源层级] A/B/C/D → 【出处定位】书名 + 卷页 / 碑刻编号 + 拓片号 / 馆藏档号 / 口述档案编号 → 【交叉印证】≥2 种独立材料或注明孤证 → 【质控签署】Q1/Q2/Q3 审核记录
```

---

## 要素一：家族起源脉络

### ① 已有框架（§03）
- 郝氏得姓的主源叙事（子姓封邑说）可作为"姓氏背景"而非"宋村始迁祖"的直接依据；
- 郡望太原堂为普遍认知，需与本支实际称谓比对。

### ② 待证问题清单

| 编号 | 问题 | 预期证据类型 | 责任字段 |
|---|---|---|---|
| O1 | 始迁祖名讳、年代？ | 谱牒序言/碑刻/墓志 | genealogy: origin始祖 |
| O2 | 迁入路线与动因（军屯/民屯/逃荒/投亲）？ | 方志·兵制/屯田记、家传口述、族产契约 | migration: 迁徙路径、动机标签 |
| O3 | 与周边村落/支系是否共祖？ | 多支谱牒对勘、坟地昭穆图 | kindred: sibling_branches |
| O4 | 字辈表全文？ | 谱中世次诗、牌位/墓碑用字 | generations: character sequence |

### ③ 调查模板（示例）

`O1 始迁祖`  
- 受访人 HXX：【转录】……其父携二子自洪洞迁赵州，居于此（录音 OR-SN-2026-01）；  
- 《郝氏族谱》（抄本，光绪十三年）序："公讳 XXX，明永乐二年，奉命从晋入冀……"（文档 DOCS-HS-2026-02）；  
- 墓刻：清 XX 年立碑文"始迁祖 X 公之墓"（拓片 TP-2026-03）；  
- **核验状态**：A×1 + C×1 → Q1 双人核对通过；  
- **结论文本**（暂空）：始迁祖 XXX，时间≈永乐二年，【推论→待核《赵州志》兵制与军户籍】。

- 滹沱河水道、古官道（京广线走廊的前身）对迁移路径的影响。

### ② 待证问题清单

| 编号 | 问题 | 证据类型 |
|---|---|---|

## 要素三：重要人物生平事迹

### ① 编年体例（每人传记不少于 3000 字）

1. **生平概述**（500 字）：生卒、字号、出身支系、主要成就定性；
2. **编年事略**（1500+ 字）：逐年列表，每条目至少一项证据；
3. **贡献分析**（500+ 字）：在地方社会的角色（士绅/商人/工匠/教习/公职等）、影响评估；
4. **史料注释**（末尾）：引文出处与歧说处理。

### ② 待证问题清单（按历史时期分类）

| 时期 | 检索方向 |
|---|---|
| 明清 | 科举名录（举人/进士）、行迹见于方志选举志/艺文志者；家族内部“家传”“行状” |
| 民国 | 地方职官名录、商会/学校记录、报刊报道 |
| 现代 | 公社干部/劳模/教师/技工名录、立功受奖档案 |

## 要素四：家族重要文献资料

### ① 文献数据库建设标准（新增系统集合 `research_sources`）

| 字段类别 | 具体字段 | 说明 |
|---|---|---|
| 基本元数据 | `sourceType` (谱牒/碑刻/契约/家书/地契/账簿) | 标准化枚举 |
| 断代考证 | `datingEvidence`, `periodLabel` | 如“清乾隆年间（据纸墨印色）” |
| 可靠性等级 | `reliabilityScore` (1–5)、`evidenceLevel` (A/B/C/D) | §01 方法 |
| 原文转录 | `transcriptionText` | UTF8 编码 |
| 图像载体 | `imageUrls[]` | 原始影像、高清扫描件 |
| 学术价值 | `academicValueNote` | 释读要点、校勘差异 |
| 典藏位置 | `repository`, `catalogNo` | 若藏于家中，标记"家藏 NO.XX" |

### ② 释读规范

- 文言原文：保留原字，异体字以"[通]"标注通行写法；
- 句读与分段：依文意重排，加编者注；
- 专有名词：人名/地名/官名首见处加注同义词。

## 要素五：传统习俗

### ① 五大活动流程图谱（田野优先）

- 婚礼：六礼简化版在河北平原的变体；
- 丧礼：孝服等级、主祭顺序、送殡仪轨；
- 祭祖：清明、十月一、忌日，合祭/分祭；
- 节庆：春节拜年序列、元宵走会、七月半、十月初一；
- 命名礼：取小名/上谱、长幼次序。

### ② 变迁轨迹分析模板

```
[习俗名称] 
→ 原始形态（口述/旧照） 
→ 近现代变形（政治运动、移风易俗影响） 
→ 当代复归/创新版本 
→ 功能变化（宗教性弱化？社区整合强化？）
```

### ③ 田野记录要求（§02 已详列）

至少 5 个完整活动的记录：每活动 ≥2 信源、≥1 影像、≥1 访谈纪要。

## 要素七：祠堂建筑特色

### ① 建筑测绘规范（比例尺 1:100/1:200）

- 平面布局：坐向、间数、院落尺度；
- 木作：梁架式样、柱径、斗拱有无、装饰纹样；
- 石刻：门神/抱鼓石、础石雕刻；
- 彩绘：主题图案（花卉/吉祥纹）。

### ② 若无祠堂

以**坟地祭祀空间**作为替代对象：碑碣排列、祭祀台、戏楼遗迹等；同时扩展"公共议事场所"（庙宇/学校教室/大队部）的历史角色调查。

## 要素八：与地方历史事件的关联

### ① 关联类型矩阵

| 事件类型 | 可能关联方式 | 检索线索 |
|---|---|---|
| 军事 | 从军/兵役/保甲 | 县志兵事志、服役档案、烈士名录 |
| 政权 | 乡政任职、胥役 | 民国户籍/社队干部名单 |
| 社会变迁 | 土改成分划分、合作化 | 土改档案、农业税册 |
| 文化教育 | 私塾教师、办学参与 | 学校校友录、教师名册 |
| 灾异与水利 | 黄河决口/滹沱河治理 | 水利档案、族内救灾记录 |

### ② 关联强度判定

- S 级：直接参与（档案记载本族成员姓名 + 角色 + 时间）；
- A 级：间接参与（集体事件中本族成员集中出现/牺牲较多/获得表彰群体）；
- B 级：影响性（本支因地域而受影响，但有量化支撑）。

## 完成标准（每一要素达到以下条件方可进入下一轮）

1. 证据密度：核心结论至少有两项独立证据；
2. 交叉验证：口述与文献一致或矛盾处理完成（± 注释）；
3. 外部同行评议：至少一位外部评审签署意见；
4. 三级质控签字：Q1-Q3 全部闭环；
5. 系统录入：对应 schema 字段的原始数据已保存，证据附件上传。
