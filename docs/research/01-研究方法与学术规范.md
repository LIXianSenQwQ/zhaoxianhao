# 01 研究方法与学术规范（总纲）

> 项目：好诚事家风 · 赵县宋村郝氏家族史研究体系  
> 版本：v1.0（方法框架定稿；实证材料按田野进度滚动补充）  
> 适用范围：本项目全部研究者、整理者、审核者

---

## 0. 学术诚信红线（先于一切方法）

本项目为学术性家族史研究，以下行为**绝对禁止**，违者成果作废：

1. **禁止虚构史料**：不得编造文献条目、卷页码、馆藏编号、碑刻录文、访谈记录。
2. **禁止以通代专**：不得将全国性/泛姓通史内容径直当作本家族史实陈述，凡通史推论必须标注"推论"字样并说明依据。
3. **禁止精确度造假**：无据不标"精确到月"的生卒；无法断代的不标年代。
4. **禁止口述拼贴**：口述资料必须保留原始录音/影像，转录不得与录音不符。
5. **凡家族专属信息（本支世系、迁徙、人物、习俗、文献、祠堂）在取得实证前一律标注【待田野考证】**，不得以想象补足。

> 本仓库（软件系统）内的一切家族史内容，必须能回溯到：一手史料、公开出版文献、或带原始记录的田野调查三者的至少其一。无法回溯的，系统内不得作为"已证实"展示。

## 1. 三大研究方法与操作规范

### 1.1 田野调查法（Fieldwork）

**适用对象**：习俗活动（婚丧嫁娶、节庆、祭祀）、祠堂建筑、地名与景观、实物文献的发现与登记。

**操作规范**：
- 调查前必须完成《田野调查方案》（见 02 号文件）并经项目负责人批准；
- 每次调查形成**调查日志**：时间、地点、参加者、访谈对象、获取材料清单、当日工作笔记；
- 实物拍摄遵循"多角度 + 比例尺 + 原始环境"三原则，照片即时编号（格式：`SC-YYYYMMDD-序号`）；
- 涉及个人隐私（生卒、婚姻、疾患、经济状况）须取得当事人或其直系后人**书面知情同意**。

### 1.2 文献考证法（Documentary Research）

**史料分级**（引证时必须标明级别）：

| 级别 | 定义 | 例 |
|---|---|---|
| A 一手史料 | 当时人记当时事，或事件直接遗存 | 族谱原抄本、祠堂碑刻、契约文书、地契、账簿、家书 |
| B 同代旁证 | 与事件同时代但非当事家族所记 | 地方志、官修典籍、同时期文集、报刊 |
| C 后出追记 | 后代据前代资料整理，有明确所本 | 清修方志引明档、民国重修谱、今人整理汇编 |
| D 转述性材料 | 无明确所本的传抄、传闻、网络内容 | 村中传说、网络百科、口传世系 |

**考证规则**：
1. 任何结论原则上需 **≥2 种相互独立的史料**支持；单一 A 级史料可成立但须标注"孤证"；
2. 存在矛盾记载时，做**史料批判**（外部批判：真伪与年代；内部批判：作者立场与书写动机），并保留歧说；
3. D 级材料只能作为"线索"，不得作为"证据"引用；
4. 引证必须落实到**可检索位置**：书名 + 卷次/篇目 + 页码，或碑刻编号，或馆藏单位 + 档号。无法落实位置的引文视同未引。

**引用格式**（本目统一采用国标 GB/T 7714 风格的家族史简化版）：

```
古籍：[朝代] 作者. 书名[M]. 卷次. 版本/馆藏信息, 页码.
方志：[朝代] 修纂者. 《X县志》卷X·志X. 版本, 页码.
现代：作者. 书名[M]. 出版地: 出版社, 年份: 页码.
论文：作者. 篇名[J]. 刊名, 年份, 卷(期): 页码.
档案：馆藏单位. 档案题名: 档号(年代).
口述：受访人(辈分/年龄). 访谈记录编号, 访谈人, 时间, 地点.
```

### 1.3 口述史记录法（Oral History）

**适用对象**：家族记忆、迁徙传说、习俗细节、人物行状、近代以来事件。

**操作规范**（细则见 02 号文件）：
- 录音/录像为**必须**项；仅笔录不录音的口述只能记为"传闻"级材料；
- 转录采用逐字稿原则，方言词保留原音并用括号注通行写法；
- 每份口述建立"访谈档案卡"：编号、受访人信息、访谈提纲、原始载体、转录稿、考证注释；
- 口述与文献冲突时：两者并陈，由考证程序裁定，不得径改口述。

## 2. 三级质量控制体系

| 层级 | 名称 | 责任人 | 核验内容 | 通过标准 |
|---|---|---|---|---|
| Q1 | 史料真实性核验 | 两名整理者**双人交叉** | 材料存在性、录文与原件一致性、引证位置可检索 | 双人独立核验结果一致；不一致的降级存疑 |
| Q2 | 学术严谨性审查 | 项目内"同行"评议员（家族外具备史学训练者 ≥1 人；暂缺时以外部顾问书面意见替代） | 论证链完整、歧说处理、术语规范、以通代专 | 评议意见全部闭环（接受/说明理由驳回） |
| Q3 | 研究方法规范性检查 | 项目负责人 | 是否按本规范执行（调查伦理、引用格式、档案完整） | 检查表逐项通过，留档签字 |

**档案要求**：每一结论条目在系统/汇编中以"证据链"呈现：`结论 → 证据 1..n（级别+位置）→ 考证过程 → 审核人+日期`。

## 3. 术语与标注约定

- `【待田野考证】`：家族专属信息缺实证，禁止当作事实展示；
- `【歧说】`：史料矛盾并陈；
- `【孤证】`：单一 A 级史料支持；
- `【推论】`：由通史/区域史作出的、需田野验证的推断；
- `【转录】`/`【节录】`/`【概述】`：口述处理方式三级标注；
- 年代写法：历史纪年用"庙号/年号 + 公元"，如"（明永乐二年，1404）"；不清者写"？—？"，不确定月份不写月。

## 4. 与软件系统的对应关系

本规范直接约束"好诚事家风"系统的数据录入与展示：

| 系统集合 | 对应研究概念 | 规范约束点 |
|---|---|---|
| `members` | 世系实体 | 生卒年必须带证据链方可展示精确值 |
| `documents` | 文献数据库 | 断代/释读/价值评估字段 |
| `research_sources`（新增） | 史料引证体系 | A/B/C/D 分级、馆藏号、可靠性 |
| `oral_interviews`（新增） | 口述史档案 | 受访人、提纲、载体、转录、考证 |
| `folk_customs`（新增） | 习俗田野记录 | 流程图谱、变迁轨迹、影像清单 |
| `research_profiles`（新增） | 人物学术档案 | 编年、贡献分析、传记状态 |

录入端（管理后台/云函数）校验：A/B/C 级证据必须填"可检索位置"，否则拒绝保存为"已证实"状态。
