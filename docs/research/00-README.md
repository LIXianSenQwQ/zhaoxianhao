# 好诚事家风 · 宋村郝氏家族史学术研究体系

> 版本 v1.0 ｜ 性质：**研究框架与规范体系**（实证材料随田野进度滚动归档）  
> 位置：本仓库 `docs/research/`，与系统数据结构（`cloud/db-schemas/`）联动

## 学术诚信总声明

本体系**只承认三种知识来源**：一手史料（含数字化影像）、公开出版/馆藏文献、带原始记录的田野调查。  
系统与文档中一切家族专属结论必须挂证据链；凡未取得实证处一律标注 `⟪待田野考证⟫`。**禁止任何形式的虚构（编造引文、访谈、馆藏号、精确生卒）**——这是本项目的第一纪律（详见 01 号文件 §0）。

## 系统支撑（数据结构）

新增研究类集合（见 `cloud/db-schemas/`）：

| 集合 | 对应研究概念 |
|---|---|
| `research_sources` | 史料引证体系（A/B/C/D 分级、馆藏定位、断代、转录） |
| `oral_interviews` | 口述史档案（受访人、提纲、载体、转录、考证注释） |
| `folk_customs` | 民俗活动田野记录（流程图谱、变迁、影像清单） |
| `research_profiles` | 人物学术档案（编年、贡献分析、传记状态、证据链） |

系统校验纪律：`research_sources`/`oral_interviews` 的 A/B 级条目必须携带 `location`（可检索位置）或 `fileId`（原始载体）方可置为 `verified`。

## 使用路线（给研究执行者）

1. 通读 01（方法）→ 02（工具）；
2. 按 05 的待证清单制定首轮田野计划（优先 O1/O2/M1 抢救性访谈）；
3. 调查中即时建档（02 §六台账），材料入 `archives/`；
4. 每月按 06 验收清单滚动产出"工作稿版"成果；
5. 全部要素达 05"完成标准"后，产出正式汇编版。
