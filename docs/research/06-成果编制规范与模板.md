# 06 成果编制规范与模板（六类交付物）

> 本文件规定最终成果的**标准格式**。所有模板均为"空骨架 + 填写规则"，**不含任何未经实证的家族事实**；示例占位一律以 `⟪待田野考证⟫` 标出。

---

## 成果一：经严谨考证的家族世系表

**格式**：分层树状表格（兼容 GB 世系图惯例 + 系统内 `members.path` 物化路径）

```
| 世代 | memberNo | 谱名 | 生卒年(精度) | 配偶 | 主要官职/成就 | 证据编号 |
|------|----------|------|--------------|------|----------------|----------|
| 1    | 001      | ⟪待田野考证⟫ | ⟪待田野考证⟫ | | | |
```

**填写规则**：
1. 生卒年精度分三级标注：`年`（如 1901）/`年月`（1901.03）/`不详（—）`；
2. 每一行必须挂至少一条证据编号（指向 research_sources 或 oral_interviews 档案）；
3. 无证据的行不得进入"已证实"版本，仅在"工作稿"版本保留并标 `⟪待田野考证⟫`；
4. 系统内与 `members` 集合一一对应，`path` 字段即本表树形结构的机读形式。

## 成果二：家族重要事件编年表

```
| 年份 | 事件 | 性质 | 史料来源（文献名+卷/页 或 档号 或 口述编号） | 考证等级 |
|------|------|------|--------------------------------------------|----------|
| ⟪待田野考证⟫ | | | | |
```

**规则**：年份不确切者记为 `约XXXX年` / `XXXX—XXXX年间`，并在"考证等级"注明推断依据；每条事件必须有**可检索位置**。

## 成果三：代表性人物传记（学术体例，≥3000 字/人）

结构（固定五段式）：
1. **传主小传**（≈500 字）：名、字号、生卒、世系定位、身份定性；
2. **生平编年**（≈1500+ 字）：按年列表式叙述，逐年条目皆挂证据编号；
3. **主要事迹深描**（≈800 字）：选 2–3 件核心事迹做过程性重建；
4. **历史影响分析**（≈300 字）：对家族/村落/区域的作用，区分"事实影响"与"记忆影响"；
5. **史料与歧说**：引用清单 + 矛盾材料并陈说明。

**硬性规则**：字数不足、无证据条目占比>20%、或缺"歧说"一节者，退回修改。

## 成果四：家族文化习俗专题研究报告

结构：
1. 导论（研究问题、方法、材料）；
2. 习俗本体描述（流程图谱：阶段 → 参与者 → 用物 → 忌讳 → 时长）；
3. 变迁轨迹（三代对比：祖辈—父辈—当代）；
4. 文化内涵分析（功能主义 + 象征人类学双视角）；
5. 田野原始记录附录（访谈纪要编号、影像清单）。

**附件规范**：影像/音频逐条编号（与 oral_interviews 档案一致），报告正文引用时以 `[OR-编号]` 格式挂链。

## 成果五：家族文献资料汇编

分类体例（按 sourceType）：
```
卷一 谱牒类
  1. 《郝氏族谱》（清光绪抄本）【A】
     - 原文（影印编号：DOC-IMG-xxxx）
     - 释文（标点校勘版）
     - 考证注释（断代依据、讳字、避讳、阙文处理）
卷二 碑刻类 …… 卷六 契约文书类 ……
```

**每件文献必须包含**：原文转录、释文（现代标点）、断代考证（依据）、学术价值评估（该件对哪一要素有何贡献）。

## 成果六：研究方法说明与学术规范声明

固定文本（使用时填空）：
- 研究时段与空间范围；
- 三大方法（田野/文献/口述）的具体应用过程与材料量统计；
- 三级质控的执行记录（Q1 双人签署清单、Q2 评议意见书、Q3 检查表）；
- **学术伦理声明**：知情同意执行情况、隐私处理、原始档案保存位置；
- **局限性声明**：明确列出尚未解决/存疑的问题（对应 05 号文件待证清单的未闭合项）。

## 统一索引与参考文献体例

- 参考文献：GB/T 7714 风格，古籍/方志/档案/口述/现代文献分列；
- 索引：人名索引、地名索引、文献编号索引三套；
- 档案目录：`archives/` 按 `OR-`（口述）、`SC-`（田野日志）、`DOC-`（文献影像）、`TP-`（拓片）四前缀编目，目录文件与本模板同步维护。
