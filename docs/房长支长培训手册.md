## 二、核心操作流程（2 小时）

### 2.1 入谱工单初审 SOP

#### 场景 A: 新生儿入谱

**触发条件**: 族人通过小程序提交新生儿入谱申请

**审核步骤**:

1. **查看工单详情**
   ```
   申请人: 父亲姓名
   新生儿信息: 姓名/性别/出生日期/兄弟姐妹
   证据材料: 出生证明照片
   ```

2. **核对关键信息**
   ```markdown
   ✓ 父亲是否为本支在册成员？
   ✓ 母亲信息是否需要单独建档？
   ✓ 出生日期公历/农历双记是否完整？
   ✓ 兄弟姐妹 siblingOrder 排序是否合理？
   ✓ 谱名是否符合字辈诗（generationChar 匹配）？
   ```

3. **执行审核动作**
   - 全部通过 → 点击 `FIRST_PASS` 按钮
   - 发现问题 → 填写驳回理由 → `REJECT`

#### 场景 B: 迁入入谱

**触发条件**: 外分支族人迁入本支

**审核步骤**:

1. **验证原分支证明**
   - 要求提供原分支支长签字的《迁出证明》
   - 核对原分支是否已标记为迁出状态

2. **核对世代一致性**
   ```javascript
   // 世代计算校验
   const newGen = sourceBranchFoundingGen + generationsSinceMigration;
   const targetGen = currentBranchFoundingGen + generationsSinceLocalFounding;
   // 两者应一致，否则需人工调整
   ```

3. **记录迁徙详情**
   - 迁出时间
   - 迁入时间
   - 迁徙原因（务工/婚姻/求学等）
   - 原居地详细地址

#### 场景 C: 过继/收养入谱

**触发条件**: 非亲生子女纳入本支谱系

**审核步骤**:

1. **证据收集清单**
   - [ ] 过继协议原件（或复印件）
   - [ ] 见证人证言（口述录音）
   - [ ] 双方家族同意书
   - [ ] 现户籍证明

2. **关系类型标注**
   ```json
   {
     "type": "PARENT_CHILD",
     "subType": "ADOPTED",
     "startDate": "2020-01-01",
     "sourceTags": ["过继协议", "见证人证言"],
     "confidence": 4
   }
   ```

3. **血缘关系保留**
   - 生父母信息保留在 aliases 字段
   - 不删除原有 PARENT_CHILD 关系
   - 新建 ADOPTED 关系类型

### 2.2 成员信息编辑 SOP

#### 修改基本信息

**操作路径**: `Member Profile → Edit`

**可修改字段清单**:
- name / genealogyName（改名需走变更审核）
- birthDate / deathDate（补录缺失信息）
- occupation / education（新增或更新）
- aliases（字号/曾用名追加）
- deeds（善行事迹补充）
- tomb（墓葬信息完善）

**不可修改字段**（须族史委审批）:
- branchId（跨支移动）
- generation（世代数）
- fatherId / motherId（血缘关系变更）
- gender（性别变更）

**编辑操作流程**:
```javascript
// 系统自动生成 audit_log
await audit_logs.insert({
  action: 'member.update',
  memberId,
  changes: diff(original, updated),
  editedBy: currentUserId,
  editedAt: new Date()
});
```

## 四、常见问题 FAQ

### Q1: 族人反映小程序提交后收不到回复？

**A: 排查步骤**

1. **检查工单状态**
   ```
   SUBMITTED → FIRST_PASS → SECOND_PASS → PUBLICITY → APPROVED
   ```

2. **确认通知渠道**
   - 微信模板消息是否订阅？
   - 手机号是否填写正确？

3. **联系支持**
   - 若状态已 APPROVED 但未显示 → 联系 dev team
   - 若长时间无审核 → 联系族史委协调

---

### Q2: 如何处理族人对审核结果的异议？

**A: 处理流程**

1. **倾听诉求**: 记录异议内容和依据
2. **内部复核**: 与另一名支长交叉复核
3. **提交族史委**: 若双方无法达成一致
4. **最终裁决**: 族史委集体讨论决定
5. **回复族人**: 说明最终结论和依据

**禁止行为**:
- ❌ 直接驳回族人的合理申诉
- ❌ 绕过流程私下修改数据
- ❌ 与族人发生冲突

---

### Q3: 发现数据错误但自己没有权限修改怎么办？

**A: 处理路径**

| 错误类型 | 处理方式 |
|---------|---------|
| 基本信息错误（name/occupation） | 直接编辑保存 |
| 关系错误（fatherId 错误） | 提交工单至族史委 |
| 世代数错误 | 提交工单至族史委 |
| 跨支归属错误 | 提交工单至族史委 |

**工单提交规范**:
```
标题: [数据纠错] 郝某 fatherId 错误
描述: 当前 fatherId=HAO-001（错误），应为 HAO-002（正确）
依据: 依据 1865 年家谱第 15 页记载
证据: [附件] 家谱扫描件
```
