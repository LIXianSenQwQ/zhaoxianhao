## 🚀 部署步骤

1. **环境准备**  
   - 小程序管理后台：确保 feature flag 开关默认开启（global）。  
   - 云开发控制台：内容安全（msgSecCheck）已开；短信模板审核通过。

2. **构建与部署**  
   ```bash
   npm run build:mp-wechat     # 前端打包
   tcb deploy --env prod       # 推送最新云函数（新增 home/opera/secscan）
   ```

3. **灰度放量**（推荐策略）  
   - 第 1 轮：5 人内测 48h → 观察 crash/延迟/错误码。  
   - 第 2 轮：10% → 50% → 100%（每档 24–48h，监控 metrics）。  
   - 熔断：出现 P0/P1 级问题立即回滚至上一可用版本 snapshot。

4. **审核提交**  
   - 微信公众平台 → 版本管理 → 提交审核（附“零内购/零下注/单机娱乐”说明）。
