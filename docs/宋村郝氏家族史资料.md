## 第一编 起源脉络与发展年表

### 1.1 明代迁居宋村的历史背景

**（1）时代背景〔佐证·通史〕**
元末至明初，冀中平原迭经战乱，人口凋敝。明洪武至永乐年间，朝廷组织大规模移民垦荒，山西等地民户大量迁入真定府所属州县，赵州一带为重要安置区之一。此为冀南家族普遍的立祖叙事背景；郝氏是否出自明初移民，尚无本族直接文献支撑，〔待考〕。

**（2）宋村地望〔佐证〕**
宋村位于赵州城西约七里，濒洨河。村西七百米商周遗址上有西林寺塔，元至元十一年（1274）建六角砖塔，俗称白佛寺，「古佛远近驰名」；村南洨河上有济美桥，多孔敞肩石拱，建桥年代不晚于明嘉靖二十八年（1549），1933 年梁思成先生实地考察著录〔梁文〕。农耕、水源、津渡条件俱备，宜于立祖定居。

**（3）行政建置：轮城社〔佐证→待考〕**
东汪谱文称宋村属「輪城社」。「社」为明代州县以下里社建置，清初沿用后渐废——谱文保留社名，是宋村明代建置身份的直接旁证，与第一编立祖下限互证。轮城社是否见载于《赵州志》里社门类，〔待考〕（台账 Q4）。

**（4）立祖下限〔确证〕**
据地契、石碑、功德碑佐证，**明嘉靖十六年（1537）前，郝氏已迁居宋村立祖**〔宋证〕〔根脉〕。始迁祖名讳、原籍来源、迁入具体年份均无记载，〔待考〕（台账 Q3）。

### 1.3 传承年限与世次推算

- **传承年限〔推算〕**：以 1537 年立祖下限起算，至 2026 年**至少 489 年**；若系明初（洪武—永乐间，约 1368—1424）迁入，则传承可达六百年上下〔存疑〕。准确年限须待始迁祖迁入年份考实后方能锁定。
- **世次推算〔推算〕**：489 年按每代 26—28 年计，约传 17—19 世以上。**本支实际世次须以宋村谱牒、祖茔碑刻为准**，本推算仅作征集线索使用。
- **校验锚点**：东汪 1981 年重修谱「时共十四世」（自屺瞻公起算）为重要旁证，其与迁出年份的互校见第三编 3.3。

### 1.4 早期世系缺口

宋村本支自始迁祖以下各世名讳、配偶、茔葬方位等，现存材料无载，〔待考〕。缺口填补路径与字辈考证共用同一套田野方法（第二编），一并执行。

## 第三编 宁晋东汪分支关系考证

### 3.1 谱文原文照录

东汪郝氏家谱载（〔东谱〕卷首；所属修本与页码待编目）：

> 「祖居直隶趙州城西七里宋村輪城社社二家二门由始祖讳屺瞻者遷于宁晋县东汪村」

**照录说明**：原文保留「趙」「輪」「遷」等繁体字形及「社社」叠字，均按原件录入，不做回改。

### 3.2 原文校注（逐词）

| 词句 | 校注 |
|---|---|
| 祖居 | 东汪支追述祖源之辞：本支祖居地为赵州宋村 |
| 直隶 | 明代为北直隶，清初始单称直隶（1928 年改河北省）。谱文单称「直隶」，行文口径更近清制，与同治四年（1865）首修年代相符；亦不排除承袭明末旧文〔佐证〕 |
| 趙州 | 「趙」为「赵」之繁体。赵州即今河北赵县（1913 年废州改县） |
| 城西七里宋村 | 宋村方位：赵州城西约七里，与今地望及西林寺塔、济美桥诸坐标互证〔佐证〕 |
| 輪城社 | 「輪」为「轮」之繁体。轮城社为宋村所属里社建置，系明代州县以下单位，为宋村明代建置身份之直接旁证；是否见载《赵州志》〔待考〕（Q4） |
| 社二家二门 | **断句难点〔存疑〕**（Q2）。两种释读：①「輪城社／社二家／二门」——轮城社内「社二家」之两门；②「輪城社／二家二门」——郝氏于社中为「二家二门」两门份。第二「社」字是否抄写衍字，须核原谱影印件 |
| 由始祖讳屺瞻者 | 东汪支尊**屺瞻公**为其始祖（即始迁祖）。「讳」为对已故先人名讳之敬称 |
| 遷于宁晋县东汪村 | 迁入地：宁晋县东汪村（今宁晋县东汪镇驻地〔佐证·区划待核〕，Q7） |

**参考断句**：「祖居直隶趙州城西七里宋村輪城社，社二家二门，由始祖讳屺瞻者，遷于宁晋县东汪村。」

### 3.3 迁出时间考〔存疑〕

谱文本身**未系年**。现有三种口径：

| 口径 | 内容 | 性质 |
|---|---|---|
| 〔根脉〕 | 清康熙五十四年（1715）前后迁出 | 推算——「比宋村晚约 178 年」（1537＋178＝1715），系机械推算，非谱载纪年 |
| 〔蓝本〕 | 约 1740 年前后迁出 | 蓝本沿写，无独立依据 |
| 〔东谱〕 | 1981 年重修时「共十四世」（自屺瞻公一世起） | 谱载世次 |

**世次逆推算式〔推算〕**：自一世至十四世共 13 个世代间隔。

- 按每代 28 年：1981 − 13×28 ＝ 1617 → 迁出当在明万历末；
- 按每代 25 年：1981 − 13×25 ＝ 1656 → 迁出当在清顺治间；
- 而「1715 年迁出」对应每代约 20.5 年、「1740 年迁出」对应每代约 18.5 年，均明显短于常值。

**结论**：世次证据更支持**明末清初（约 1600—1660）迁出**；但「十四世」或指 1981 年在世最高辈分而非已出生代数，且早年世代间隔可能偏短，故不据此独断。**迁出年份列为头号待考项（Q1）**。

**校准方法**：征集东汪谱中生卒纪年最完备之三代人物与宋村谱同辈对读，以父子年龄差锁定世代间隔后重算。

### 3.4 历史地理与迁徙背景分析

1. **州域内迁徙〔佐证→待核〕**：明代赵州属真定府、领宁晋等县；清雍正二年（1724）后赵州为直隶州，宁晋为其属县〔赵志·建置卷待核〕。屺瞻公由州域宋村迁入属县东汪，**迁徙不出赵州域**，属典型的州内短距离分迁——这一地缘条件解释了两支世系得以长期保持谱牒互识的原因。
2. **迁徙形态〔佐证〕**：由州城近郊向属县平原，里程短、方向明确，与清初州域内人口扩散的一般形态吻合；宋村临洨河、近州城的区位，亦便于与属县保持往来。
3. **迁徙动因〔存疑〕**：清初垦殖置业、婚娅联结、族支析产等均属常见动因，本族具体动因无载，仅列入口述访谈提纲（附录 D），不得臆断。
4. **「二家二门」与分迁〔存疑〕**：若 3.2 释读②成立，则屺瞻公迁出时宋村郝氏已至少两门并存，东汪支或出自其中一门。此点有待碑刻、口述验证。
