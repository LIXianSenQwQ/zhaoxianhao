# 「好诚事家风」郝氏家谱系统 · 宋村郝氏试点部署实施计划

> **版本**: V1.0 (试点版)  
> **制定日期**: 2025-01-XX  
> **预计周期**: 12 周（含 UI 深度开发 + 首批族人培训）

## 一、部署目标与里程碑

### 1.1 总体目标

在**12 周内**完成宋村郝氏分支数字化迁移，实现：
- ✅ **数据迁移**: 18-20 世系完整录入，覆盖 95% 以上现存族人
- ✅ **UI 上线**: 宋村专属首页「根脉·荣光·记忆」三维展示
- ✅ **培训完成**: 族史委 5-8 人全员掌握审核流程，15-20 名支长能独立编辑
- ✅ **试点验收**: 首版 PDF 谱书生成 + GEDCOM 导出测试通过

### 1.2 核心里程碑

| 里程碑 | 时间节点 | 交付物 | 负责人 |
|--------|---------|--------|--------|
| **M1: UI 原型确认** | 第 2 周 | 高保真原型 + uni-app 集成方案 | UI 组 |
| **M2: 数据迁移启动** | 第 3 周 | 数据收集模板下发 + OCR 识别工具 | 族史委 |
| **M3: 首批入谱审核** | 第 6 周 | 10-15 条入谱工单闭环 | 族史委 |

## 五、KPI 验收指标

### 5.1 数据质量指标

| 指标 | 目标 | 计算公式 |
|------|------|---------|
| 数据来源标注率 | 100% | `sourceTags.length >= 1` / total_members |
| 世代连续率 | 98%+ | `(child.generation === parent.generation + 1)` / total_relations |
| 谱名唯一率 | 100% | unique(genealogyName, generation, branchCode) / total_members |
| 双人审核率 | 100% | audit_logs.count(2 人) / total_audit_actions |

### 5.2 系统性能指标

| 指标 | 目标 | 测量方式 |
|------|------|---------|
| 首屏加载时间 | ≤1.5s | Lighthouse 测试 |
| 谱系树渲染延迟 | <800ms (500 节点) | console.time() |
| 搜索响应速度 | ≤500ms | network timing |
| 并发在线人数 | ≥50 人 | 压力测试 |

### 5.3 用户参与指标

| 指标 | 目标 | 计算方式 |
|------|------|---------|
| 族史委培训合格率 | 100% | 实操测试得分≥80 分人数 / 总人数 |
| 支长独立完成入谱审核 | ≥80% | 首月独立完成数 / 总工单数 |
| 普通族人提交入谱申请 | ≥50 份 | first_month_submissions |
| 用户满意度评分 | ≥4.5/5 | 问卷调查平均分 |
