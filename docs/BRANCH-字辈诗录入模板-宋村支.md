# 宋村支字辈诗录入模板（交支长填写）

> **用途**：宋村支字辈诗权威文本征集。填妥后交族史委 EDITOR，经 `branch.update` 录入宋村支谱（`generationVerses` 字段）。
> **说明**：本模板对应简报决策点③（字辈诗权威文本待族史委提供）。**请只填本模板，不要改其他文档。**
> **填写版式**：直接在下方「填写区」作答；不确定处写「存疑：……」，切勿留空或编造。

---

## 录入流程（族史委 EDITOR 使用，支长无需操作）

1. 核对模板内容与文献出处；
2. 管理端打开对应分支（如「宋村一支」，code=`HAO-0000-01`）；
3. 调用 `branch.update`：

```js
// 云端控制台或管理页调用（EDITOR+）
wx.cloud.callFunction({
  name: 'branch',
  data: {
    action: 'update',
    code: 'HAO-0000-01',           // 宋村支谱
    generationVerses: '（字辈诗全文，≤500 字）',
    // description: '（可选：渊源说明摘要）'
  }
});
```

4. 录入后系统自动写审计（action=`branch.update`，target=分支编码）；
5. 前端族谱页/分支详情页读取 `generationVerses` 展示（字段上限 500 字，超出请拆入 description 或谱牒文档）。

## 验收标准

- [ ] 字辈诗全文 ≤50 代、与文献出处一致
- [ ] 渊源说明四项齐全（朝代/编撰人/出处/使用范围）
- [ ] 存疑项逐条标注，未发现臆造
- [ ] 录入后 `branch.detail` 可查、审计有痕
