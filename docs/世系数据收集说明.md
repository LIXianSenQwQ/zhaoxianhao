# 世系数据收集说明（试点 200 人 · 族务对接用）

> 配套文件：`世系数据收集模板_试点200人.csv`（用 Excel/WPS 直接打开填写）
> 填完后交开发侧，由 `entry.importExcel` 导入 → 双人核对 → 入库 members/relations

## 一、填写纪律（零冲突目标）

1. **日期格式**：`YYYY-MM-DD`；不确定的写「约」前缀，如 `约1900-05`；在世者「逝世日期」留空
2. **世代数**：自始祖起算，同一支必须连续（父亲世代 = 子世代 - 1），开发侧会做互指校验
3. **房支**：统一用族议会定名的支名（如「长房」「二房」），不要自创简称
4. **排行**：同父母下的出生顺序（1、2、3…），独子填 1
5. **父母姓名**：必须与本表或族谱中某人「本名」完全一致，才能自动挂接关系边
6. **隐私**：身份证号、病历、财务等**不要填入本表**；墓葬坐标在试点阶段一律不收集
7. **信息来源**：每条尽量标注「口述 / 老谱 / 碑刻 / 文书」，存疑标「推测」

## 二、列说明（与 members 集合对应）

| 列 | 必填 | 对应字段 | 说明 |
|---|---|---|---|
| 本名 | ✅ | name | 身份证上的名字 |
| 谱名 | ✅ | genealogyName | 姓+字辈字+名；不确定可留空，由系统按字派表生成 |
| 性别 | ✅ | gender | 男 / 女 |
| 出生日期 |  | birthDate | YYYY-MM-DD 或「约1900-05」 |
| 逝世日期 |  | deathDate | 同上；在世留空 |
| 出生地 |  | birthPlace | 省市区 + 村 |
| 世代数 | ✅ | generation | 自始祖起算的代数 |
| 房支 | ✅ | branchId | 长房/二房…（族议会定名） |
| 同胞排行 |  | birthOrder | 同父母下第几个 |
| 父亲姓名 | ✅（挂接用） | fatherId | 须与某人「本名」一致 |
| 母亲姓名 |  | motherId | 同上 |
| 在世状态 | ✅ | status | 在世 / 已故 |
| 职业 |  | occupation | 摘要即可 |
| 学历 |  | education | 摘要即可 |
| 字号/曾用名 |  | aliases | 多个用顿号分隔 |
| 善行事迹 |  | deeds | 一行一条 |
| 信息来源 | ✅ | sourceTags | 口述/老谱/碑刻/文书/推测 |
| 录入人 | ✅ | createdBy | 谁录入谁负责 |
| 备注 |  | specialNotes | 过继/入赘/失联等特殊情况 |

## 三、双人核对流程（W3 启动）

1. 两名族人**独立**各填一份本表
2. 开发侧用脚本 diff 两份表格，差异行人工仲裁
3. 世代/字辈/房支校验零冲突后入库
4. 入库记录写 audit_logs（谁录入谁负责）
