# 「好诚事家风」隐私政策

> 版本：v1.0（随 MVP 上线生效） · 适用主体：河北省赵县宋村郝氏「好诚事家风」微信小程序
> 配套：《用户协议》《数据收集知情同意书》见 docs/compliance/
> 上线前需：① 小程序后台「用户隐私保护指引」同步本政策要点；② 族议会/族史委审阅本版并留痕

## 一、引言

「好诚事家风」（下称「本小程序」）由郝氏族务管理委员会（下称「我们」）开发运营，用于郝氏宗亲的数字家谱传承、家族治理与家庭协作。我们深知家族信息的敏感性，**以「最小必要、分级授权、可查可撤」为原则**处理您的个人信息。请您在使用前仔细阅读本政策；您勾选同意即视为已阅读并理解本政策全部内容。

## 二、我们收集哪些信息

### 2.1 基础账号信息
| 信息 | 用途 | 必要性 |
|---|---|---|
| 微信昵称、头像 | 登录与展示 | 登录必需 |
| OpenID / UnionID | 账号标识、防重复注册 | 必需 |
| 手机号（可选） | 密码协助、敏感操作验证 | 可选，加密存储 |
| IP 地址、操作日志 | 安全审计（≥1 年） | 必需（不可删） |

### 2.2 世系与族谱信息（家族成员共同维护）
- 成员档案：本名/谱名、性别、生辰/忌日、世代、房支、父/母等关系、职业学历摘要、善行事迹；
- 依据第六章「L 级隐私分级」，不同字段对**不同关系圈**可见，非全族可见；
- 身份证号、死因、病历、财务等**私密级字段不纳入本小程序采集范围**；试点阶段亦不收集墓葬坐标。

### 2.3 您主动发布的内容（V1.1/V2.0）
头像/介绍视频、相册照片、家庭问候语、本地内容、家族动态、广场发言等——均带**三级可见性**（仅自己/指定名单/认证族人），发布时由您选定。

### 2.4 位置与天气（可选）
仅当您授权定位时，用于「本地天气」城市识别；**不记录历史轨迹**，可随时关闭授权（关闭后仅手动选城市）。

### 2.5 敏感操作
修改密码、代理人设置、百年设置等敏感操作需短信验证码；验证码仅用于验证，不存储明文。

## 三、我们如何使用信息

1. 提供核心功能：登录认证、族谱浏览/检索、家族动态、祭祀请安等；
2. 权限判定：依据您的角色（访客/成员/房长/…）与**隐私分级中间件**决定可见字段；
3. 安全与审计：识别越权访问、异常操作，留存关键操作审计日志；
4. 个性化（可选）：节气氛围、天气、家风家训推荐——仅使用您已授权的数据，不做第三方画像广告。

**我们不会**：出售您的个人信息；将家谱数据用于无关第三方；在您未授权时向族外展示。

## 四、三级可见性与授权（重点）

| 级别 | 含义 | 默认适用 |
|---|---|---|
| PRIVATE | 仅您本人 + 您指定的受托代理人 | 头像、私密相册等 |
| GROUP | 指定名单（≤50 人）或指定组（家庭/房支） | 家庭问候语等 |
| PUBLIC | 所有认证族人可见 | 主动公开的展示内容 |

- 发布前必须选择可见级别；相册级权限可一键下发到照片，单张可覆盖（取更严格侧）；
- **权限变更即时生效**并写审计日志、在通知中心留「权限变更」条目；
- 您可随时在「我的 → 隐私设置」查看/撤回授权。

## 五、私密委托与百年设置（可选功能）

- **私密委托**：可指定 ≤3 名认证族人代理查看您的私密内容；授权需「主密码+短信」双确认，可单条或全部撤销，撤销即时生效；
- **百年设置（定时解密）**：您可预设未来日期后自动解密指定内容；到期前 7 天提醒、到期后不可逆；每次查看记录查看人与时间。**请谨慎使用本功能——一旦设定到期自动解密，将无法撤回。**

## 六、信息的存储与保护

| 项 | 措施 |
|---|---|
| 存储位置 | 腾讯云（中国大陆）云开发环境；密钥托管与轮换 |
| 传输 | 全链路 HTTPS |
| 密码 | 仅存哈希（pbkdf2 + 独立盐），永不落明文 |
| 私密内容 | AES256 加密（证件资料等敏感类强制 PRIVATE + 加密） |
| 审计 | 关键操作日志保留 ≥1 年，不可删除 |
| 访问控制 | 云函数统一鉴权 + 隐私中间件，端上不做信任判断 |

## 七、您的权利

1. **查阅**：查看本人资料与授权记录；
2. **更正**：更正本人可编辑信息（涉族谱正式字段走修谱流程）；
3. **删除/注销**：在「我的 → 设置」申请注销账号；注销后删除可识别的个人账号数据，但**已并入族谱的世系信息与审计日志**因家族共有与安全需要保留（去标识化）；
4. **撤回授权**：随时关闭定位、订阅消息、受托代理等授权；
5. **投诉**：联系族史委或通过小程序反馈入口提出，我们 15 个工作日内答复。

## 八、未成年人

少年模式自动开启内容与时长限制；未满 14 周岁用户需监护人同意后使用，且不参与涉及社交公开互动的功能。

## 九、第三方服务

腾讯云开发（云函数/数据库/存储）、腾讯 IM（群聊）、腾讯 OCR（老谱识别）、腾讯地图/位置（天气定位）、和风天气、数据万象 CI、媒体处理 MPS、腾讯云短信、新闻资讯源（仅标题+摘要+外链）。各第三方按各自隐私政策处理数据，我们仅在必要范围共享。

## 十、政策更新

本政策变更将：① 在小程序内显著公告；② 涉及收集范围扩大时重新取得同意；③ 历史版本存档于族务档案。继续使用即视为接受更新后政策。
